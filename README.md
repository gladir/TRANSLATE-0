# TRANSLATE-0
Suite de commande écrit en Turbo Pascal/Free Pascal pour la traduction de texte linguistique

<h2>Liste des fichiers</h2>

Voici la liste des différents fichiers proposés dans TRANSLATE-0 :

<table>
		<tr>
			<th>Nom</th>
			<th>Description</th>	
		</tr>
		<tr>
			<td><b>ARGOS-TRANSLATE.PAS</b></td>
			<td>Cette commande permet de traduire une phrase entre l'anglais, le français, l'allemand, l'espagnol, l'albanais, le portugais, le suédois, le danois, l'italien, le latin, le gallois, l'afrikaans, le maltais, l'islandais, le néerlandais, le norvégien, le polonais, le roumain, le catalan et le japonais (romaji).</td>
		</tr>        		
</table>

<h2>Compilation</h2>
	
Les fichiers Pascal n'ont aucune dépendances, il suffit de télécharger le fichier désiré et de le compiler avec Free Pascal avec la syntaxe de commande  :

<pre><b>fpc</b> <i>LEFICHIER.PAS</i></pre>
	
Sinon, vous pouvez également le compiler avec le Turbo Pascal à l'aide de la syntaxe de commande suivante :	

<pre><b>tpc</b> <i>LEFICHIER.PAS</i></pre>
	
Par exemple, si vous voulez compiler ARGOS-TRANSLATE.PAS, vous devrez tapez la commande suivante :

<pre><b>fpc</b> ARGOS-TRANSLATE.PAS</pre>
